# ⚔️ Ghost of Tsushima | A Clash of Honor

> A cinematic scene inspired by *Ghost of Tsushima*, recreated with HTML and CSS animations, featuring Jin Sakai, Lord Shimura, and one of the game's most memorable lines.

---

## 🖤 About The Project

**Ghost of Tsushima Dialogue** is a front-end practice project inspired by the emotional confrontation between **Jin Sakai** and **Lord Shimura** in *Ghost of Tsushima*.

The scene features the two characters facing each other from opposite sides of the background, with an invisible staircase-like composition between them. At the center of the scene, their iconic dialogue appears:

> "You have no honor."
>
> "And you are a slave to it."

The main focus of the project is to recreate the atmosphere of this confrontation through visual composition, animated text, and CSS motion.

Using **CSS animations and `@keyframes`**, the project brings movement to a static scene and gives the dialogue its own dramatic presence without relying on a complex interface.

## 🎬 How It Works

The project is built around a cinematic background featuring Jin Sakai on one side and Lord Shimura on the other.

The composition creates the impression that the two characters are facing each other across an invisible staircase, leaving the central area for the dialogue.

CSS animations introduce motion into the scene, while `@keyframes` can define how selected elements change throughout an animation sequence.

The result is a small front-end experiment that combines character artwork, typography, positioning, and motion to tell a story through a single page.

---

## 🌀 CSS Animation Techniques

This project explores the use of CSS animation to create a more dynamic visual experience.

### 🎞️ CSS Animations

CSS animations allow selected elements to change their visual properties over time, adding movement to an otherwise static composition.

### 🗝️ Keyframes

The `@keyframes` rule defines stages of an animation, allowing elements to transition through a sequence of visual states.

Example of the general CSS syntax:

```css
@keyframes example {
    from {
        opacity: 0;
    }

    to {
        opacity: 1;
    }
}
```

*This snippet illustrates the CSS concept and is not a claim about the exact animation implemented in this project.*

## 🎨 Design Direction

The design draws inspiration from the visual atmosphere of *Ghost of Tsushima*.

The composition places Jin Sakai and Lord Shimura on opposite sides of the scene, creating visual tension between the two characters.

The central dialogue acts as the focal point, connecting the characters and emphasizing the conflict between personal conviction and the traditional samurai code.

Rather than relying on a conventional website layout, the project treats the browser viewport as a cinematic stage.

The result is a visual experiment built around **honor, conflict, character placement, and CSS animation**.
